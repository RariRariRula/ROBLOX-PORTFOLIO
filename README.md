# Minimal Configurable Portfolio

Edit `js/config.js` to change your name, bio, socials, and projects. Open `idk.html` in a browser to view the site.

Quick local server (optional):

```bash
python -m http.server 8000
# then open http://localhost:8000/idk.html
```

Files:
- `idk.html` — main page
- `css/style.css` — styles and theme support
- `js/config.js` — site data (edit this)
- `js/main.js` — renderer and theme toggle
